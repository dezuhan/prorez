Prorez

Drag & drop video converter for DaVinci Resolve on Linux. GPU-accelerated ProRes & DNxHR encoding with PCM audio.

Features

Everything you need

Convert video files to DaVinci Resolve-compatible formats with GPU-accelerated encoding.

Drag & Drop

Drop video files onto the window or click to browse. Instant queue for batch conversion.

GPU Auto-Detect

NVIDIA NVENC, Intel VA-API / QSV, AMD AMF — automatically detected and configured.

ProRes & DNxHR

Apple ProRes 422 HQ/LT and Avid DNxHR HQ/SQ for mastering, color grading, and proxy editing.

Light / Dark Theme

Toggle between light and dark GTK themes. Your preference is saved automatically.

Queue + Progress

File queue with real-time progress, FPS, and speed. Handle multiple files effortlessly.

Custom FFmpeg Args

Full control with custom FFmpeg arguments. Tweak encoder, bitrate, filters, and more.

Installation

Get up and running

Install system dependencies, clone the repo, and you're ready to go.

sudo apt install python3-gi gir1.2-gtk-3.0 ffmpeg
sudo dnf install python3-gobject gtk3 ffmpeg
sudo pacman -S python-gobject gtk3 ffmpeg

Clone and run — no virtual environment needed (all dependencies are system packages):

git clone https://github.com/dezuhan/prorez.git
cd prorez
python3 prorez.py
Usage

Simple and intuitive

python3 prorez.py
  1. Drag video files into the window (or click + Add File)
  2. Select a preset matching your workflow
  3. Click Convert All

Output files are saved as prorez_convert_[original_name].[ext] in the source folder by default.

FAQ

Frequently asked

Why does DaVinci Resolve need file conversion?
DaVinci Resolve on Linux does not support H.264/H.265 files in the free version. ProRes and DNxHR are intermediate codecs that are fully supported across all Resolve editions — including the free Linux version.
ProRes vs DNxHR — which should I use?
Both are equally high-quality intermediate codecs. ProRes is more common in Apple-ecosystem workflows, while DNxHR is more cross-platform. Choose whichever your editing team prefers — the quality difference is negligible.
Does Prorez support hardware acceleration?
Yes. Prorez automatically detects available GPU encoders: NVIDIA NVENC (H.264, HEVC, AV1), Intel VA-API and QSV (H.264, HEVC, AV1), and AMD AMF (H.264, HEVC, AV1). All configuration is handled automatically.
Why are converted files so large?
Intermediate codecs like ProRes and DNxHR are intra-frame — every frame is stored independently for maximum quality and editability, at the cost of larger file sizes. Use the "HQ" presets for mastering and "LT/SQ" presets for smaller proxy files.
Can I convert multiple files at once?
Yes. Prorez has a queue system that processes files one at a time sequentially. You can drop multiple files at once, and they will be converted in order with real-time progress tracking.
What audio codec should I use?
PCM 16-bit (pcm_s16le) is recommended for DaVinci Resolve — it's uncompressed, widely compatible, and preserves full audio fidelity. AAC is also available if you need smaller file sizes.
Does Prorez work on Windows or macOS?
Prorez is built for Linux with GTK 3. Windows and macOS have not been tested yet, but we welcome feedback and contributions from users who try it on those platforms. In the meantime, you can achieve the same results with FFmpeg directly from the terminal.
