# === Python dependencies ===
# PyGObject is required but must be installed via system package manager:
#   Ubuntu/Debian: sudo apt install python3-gi gir1.2-gtk-3.0
#   Fedora:        sudo dnf install python3-gobject gtk3
#   Arch:          sudo pacman -S python-gobject gtk3
#
# === System requirements ===
#   ffmpeg:         sudo apt install ffmpeg
#   ffprobe:        included with ffmpeg
#
# Optional GPU support:
#   NVIDIA: nvidia drivers + ffmpeg compiled with nvenc
#   Intel:   intel-media-va-driver or intel-media-driver
#   AMD:     mesa-va-drivers
